# Муроблоки 1.0 — GitHub Pages + iPhone

Это версия **Муроблоков 1.0** с относительными путями, поддерживающими размещение
на GitHub Pages по адресу вида `https://USERNAME.github.io/muroblocks/`.
Игровые правила не изменены. Код всё ещё на JavaScript, без сборки.

## Опубликовать

1. Создай **публичный** репозиторий на GitHub, например `muroblocks`.
2. Загрузить надо **содержимое этой папки**, чтобы `index.html`, `game.js`,
   `styles.css`, `manifest.webmanifest` и `sw.js` лежали в корне репозитория.
   Папка `assets` тоже должна быть загружена. Загружать один ZIP нельзя.
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
4. Выбери ветку `main`, папку `/(root)` и нажми Save.
5. После публикации открой `https://USERNAME.github.io/muroblocks/`.
6. На iPhone открой адрес в **Safari** → Поделиться → На экран «Домой» → Добавить.
   При наличии переключателя включи «Открывать как веб-приложение».

**ВАЖНО:** если репозиторий называется иначе, адрес будет
`https://USERNAME.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Пути внутри игры относительные,
поэтому менять код для этого не потребуется.

## Сохранения

Прогресс хранится в локальном хранилище браузера/установленной PWA на каждом
устройстве. GitHub Pages не хранит игру пользователя на сервере. Удаление PWA
или очистка данных сайта может удалить прогресс без возможности восстановления.
В этой первой версии экспорта/импорта нет.

## Обновления

При обновлении исходников стоит менять значение `CACHE` в `sw.js`, чтобы
установленная игра не застряла на старом кэше.
